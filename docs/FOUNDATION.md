# POG Foundation

**Version:** 0.1
**Published:** 2026-08-02

## Purpose
POG (Property Operations Guide) is a standards-based operational framework for homeowners and small property owners. The framework separates reusable public guidance from private operational records.

## Core Principles
1. Public by default for reusable knowledge.
2. Private by design for property-specific information.
3. Repeatable, documented operational processes.
4. Version-controlled documentation.
5. Continuous improvement through ideas, ADRs, and decision logs.

## Repository Layers
- Public Framework
- Private Operations Repository (future)
- Secure Vault (future)
