# Photo Documentation Standard

**Document ID:** STD-PHOTO-001
**Version:** 1.0
**Status:** Adopted
**Published:** 2026-08-04

---

# Purpose

This standard establishes a consistent methodology for photographing residential properties managed under the Property Operations Guide (POG).

Standardized photographs provide visual documentation that supports inspections, maintenance, vendor management, insurance claims, property improvements, and historical recordkeeping.

---

# Objectives

Property photographs should be:

- Consistent
- High quality
- Well organized
- Easy to locate
- Useful for comparison over time
- Properly associated with the correct Property ID

---

# Photograph Categories

Examples include:

- Baseline Property
- Annual Inspection
- Move-In
- Move-Out
- Preventive Maintenance
- Corrective Maintenance
- Emergency Repairs
- Capital Improvements
- Vendor Work
- Warranty Documentation

---

# Required Photographs

## Exterior

Capture:

- Front elevation
- Rear elevation
- Left side
- Right side
- Roof (when practical)
- Driveway
- Walkways
- Fencing
- Gates
- Landscaping
- Drainage
- Utility areas

---

## Interior

Capture each room from multiple angles.

Examples:

- Entry
- Living Room
- Dining Room
- Kitchen
- Bedrooms
- Bathrooms
- Hallways
- Laundry Area
- Garage
- Storage Areas

---

## Mechanical Systems

Photograph:

- HVAC equipment
- Water heater
- Electrical panel
- Irrigation controller
- Pool equipment
- Solar equipment
- Other major systems

---

# Maintenance Documentation

For significant maintenance activities capture:

1. Before work begins
2. During work (optional)
3. Completed work

Whenever possible photograph from the same location and angle.

---

# Capital Improvements

Document:

- Existing condition
- Construction progress
- Completed project

Include wide-angle and close-up photographs.

---

# Image Quality

Photographs should be:

- In focus
- Well lit
- Landscape orientation when practical
- High resolution
- Free of unnecessary filters or edits

---

# File Naming

Suggested format:

```
PROPERTYID_YYYYMMDD_Category_Description.jpg
```

Example:

```
POG-SD-001_20260804_Inspection_Kitchen.jpg
```

---

# Metadata

Each photo collection should include:

- Property ID
- Date
- Photographer
- Inspection or Project ID (if applicable)
- Description

---

# Privacy

Avoid photographing:

- Personal financial documents
- Identification documents
- Computer screens
- Passwords
- Security codes
- Sensitive tenant information

Photographs containing private information belong only in the Private Operations Repository.

---

# Storage

Photographs should be organized by:

```
Property

    Year

        Inspection

        Maintenance

        Projects

        Move-In

        Move-Out
```

Maintain original images whenever possible.

---

# Retention

Photographs documenting significant repairs, improvements, inspections, warranties, or insurance claims should be retained for the life of the property or in accordance with applicable legal and business requirements.

# Guiding Principle

A well-documented photograph is often more valuable than a detailed written description.

Photographs should tell the property's story clearly, consistently, and objectively over time.
